# LX Music AI 助手 原生集成设计方案与实现指南

根据您的最新思路，我们彻底放弃外部 MCP Server 的方式，将 AI 助手作为 **LX Music Desktop 左侧菜单栏的专属原生功能模块** 进行深度集成。这不仅使交互更加流畅，还能完美复用应用内原有的播放器调度逻辑。

以下是实现该模块所需修改的文件清单、功能点及详细 UI 设计方案。

---

## 一、 核心功能模块划分

全新的 AI 助手模块将包含以下五个核心功能选项卡（Tabs）：
1. **AI 频道 (主界面)**：核心对话窗口。支持在【聊天模式】与【DJ 模式】之间自由切换。
2. **AI聚合搜索**：结合大模型的自然语义理解，将用户的泛意图转化为具体的搜索条件，跨内部音源引擎并行搜索并聚合结果。
3. **快捷点歌**：直接输入歌名或一句话指令，AI自动匹配并推入播放列表。
4. **历史记录**：**支持分类查看**，用户可自由选择查看纯粹的【聊天历史记录】或【推荐音乐历史记录】（包含当时的天气、心情与推荐语）。
5. **偏好设置**：包含 API 配置、双模式具体偏好设置（如聊天是否播报语音）、TTS 引擎及音色配置、人设定义、DJ 音量调节等。

## 二、 需要添加或修改的文件清单

### 2.1 路由与入口导航 (修改现有代码)
*   **修改 `src/renderer/router.ts`**:
    新增路由 `/dj`，指向我们将要新建的视图页面。
*   **修改 `src/renderer/components/layout/Aside/NavBar.vue`**:
    在 `menus` 数组中增加 `{ to: '/dj', tips: t('ai_dj'), icon: '#icon-dj', name: 'AiDj' }`。
*   **修改/新增 SVG 图标**:
    注入新的 `#icon-dj` 图标。

### 2.2 UI 视图与组件设计 (新增代码目录)
在 `src/renderer/views/` 下新建 `Dj` 目录，结构如下：
```text
src/renderer/views/Dj/
├── index.vue           # 布局主入口：提供顶部 Tab 切换
└── components/
    ├── DjChat.vue      # 聊天与DJ室 UI，顶部带【聊天/DJ】双模式切换开关
    ├── DjSearch.vue    # AI 聚合搜索框及结果列表页
    ├── DjPlay.vue      # 快捷点歌面板
    ├── DjHistory.vue   # 历史记录卡片（内置分类选项：推荐音乐/聊天历史）
    └── DjSetting.vue   # 配置表单组件
```

### 2.3 状态管理与数据持久化 (新增代码)
*   **新增 `src/renderer/store/dj/index.ts`**:
    - `currentMode`: 当前模式 (`'chat'` / `'dj'`)。
    - `chatMessages`: 聊天模式历史。
    - `recommendHistory`: 专门存储推荐过的歌曲历史及其上下文（天气、心情、时间）。
    - `config`: 各项配置信息。

### 2.4 核心业务逻辑层 (新增代码)
*   **`llmService.ts`**: 封装模型请求，根据聊天/DJ模式注入不同的 System Prompt。
*   **`ttsService.ts`**: 封装 Edge TTS。
*   **`weatherService.ts`**: 获取和风天气数据。
*   **`userProfile.ts` (用户画像学习模块)**:
    - **深度学习关系映射**: 读取应用的“我的喜爱”歌单。不仅提取歌曲标签，还会**记录和分析收藏音乐时对应的天气、日期和心情关系**。例如，系统在本地长期观察得出：“用户在下雨的周五夜晚喜欢听R&B”。
    - **动态 Prompt 生成**: 将这些总结出的人物画像规律投喂给大模型，实现极具懂你的“私人DJ”体验。

### 2.5 音频调度与【双模式】行为控制 (修改核心机制)
*   **修改 `src/renderer/core/player/index.ts` (独立音轨与混音)**:
    新增专属 `djAudio`，并实现 `playDjAudio(buffer, shouldDuck)`。若 `shouldDuck` 为 true，主音乐平滑降至 20%，语音结束后恢复。
*   **双模式行为定义**:
    - **【聊天模式】**: 纯粹的对话。默认 **不触发自动混音 (No Ducking)**。模型回复后，默认不播放语音。
    - **【DJ 模式】**: 沉浸式电台。**强制触发自动混音 (Ducking)**。模型会依据**用户画像学习成果**，生成包含推荐原因的语音串场词，播报结束后自动播放该歌曲。

## 三、 详细 UI 设计与交互规划

### 3.1 AI 频道面板 (`DjChat.vue`)
- **顶部模式切换器**：胶囊状 Toggle 开关，在 **[💬 聊天模式]** 与 **[🎧 DJ 模式]** 之间切换。
- **左半部分 (对话流)**：气泡流展示内容。DJ 模式下展示“音乐卡片”。
- **右半部分 (氛围区)**：顶部显示环境信息小组件，中间展示声波动画。
- **底部输入框**。

### 3.2 历史记录面板 (`DjHistory.vue`)
- **顶部二级导航/下拉框**：
  - **[聊天历史记录]**：回顾以往纯文本/情感交流的内容。
  - **[推荐音乐历史记录]**：以“时间轴+音乐卡片”的形式，展示 AI 曾经推荐的歌曲，并附注当时的场景（如：“2026-07-22 阵雨，因为你心情有些低落，为你播放了《阴天快乐》”）。提供一键重新收藏或播放功能。

### 3.3 偏好设置面板 (`DjSetting.vue`)
- **模式偏好设置**：聊天模式下【是否开启聊天语音播报】开关。
- **个性化推荐与画像学习**：是否允许 AI 在本地收集天气、日期、心情与收藏歌曲的关联关系来完善画像 (开关)。
- **引擎配置**：Base URL、API Key、模型名称。
- **播报人设**：聊天与DJ模式各自的独立 Prompt 输入框。
- **语音与音量**：Edge TTS 发音人选择，语音独立音量，主音乐闪避音量滑块。

### 3.4 AI 聚合搜索与点歌 (`DjSearch.vue` / `DjPlay.vue`)
复用 `src/renderer/components/common/SongList.vue` 进行高度统一的搜索结果展现。
