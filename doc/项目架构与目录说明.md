# LX Music Desktop 项目架构与目录详解

这是一个基于 `Electron + Vue 3 + TypeScript` 构建的项目。为了方便后续的二次开发、修改或新增功能，以下是该项目的具体文件结构，以及每个核心目录的具体作用：

## 整体顶层目录

```text
lx-music-desktop/
├── build-config/    # 构建配置：包含打包（Electron-builder）与开发环境启动（webpack）的脚本
├── doc/             # 项目文档存放目录
├── resources/       # 平台原生资源文件（如各平台的图标文件 icon.ico, icon.icns 等）
├── src/             # ★ 核心源代码目录（你在开发中几乎只需要关注这里）
├── package.json     # 项目依赖描述文件及 npm scripts（如 npm run dev）
└── tsconfig.json    # TypeScript 配置文件
```

---

## `src/` 核心源码目录详解

`src` 目录下的代码被明确划分为了 `common`（公共）、`main`（主进程）、`renderer`（前端渲染进程）以及 `renderer-lyric`（歌词渲染进程），这种解耦非常有利于代码复用与维护。

### 1. `src/common/` (公共模块)
这部分代码会被 **主进程** 和 **渲染进程** 共同引入。
```text
src/common/
├── config.ts                 # 全局基础配置定义
├── ipcNames.ts               # 存放所有的 IPC（进程间通信）频道/事件名，非常重要！如果要加新通信协议，须在此处定义
├── mainIpc.ts / rendererIpc.ts # 分别针对主进程和渲染进程封装的 IPC 通信底层逻辑
├── defaultHotKey.ts          # 默认快捷键映射表
├── defaultSetting.ts         # 应用的默认设置参数表
├── theme/                    # 主题相关资源、颜色变量和样式生成逻辑
├── types/                    # 共享的 TypeScript 接口（Interface）与类型定义
└── utils/                    # 共享的通用工具函数库
```

### 2. `src/main/` (Electron 主进程)
负责操作系统的原生能力调用（如文件系统、托盘、快捷键管理）及核心后端逻辑。如果你需要新增需要 **系统权限** 才能完成的功能，代码写在这里。
```text
src/main/
├── index.ts / app.ts   # 主进程的绝对入口，负责初始化应用、监听 App 启动生命周期
├── event/              # 主进程内部的事件总线，用于 `main` 内部各模块间的解耦通信
├── modules/            # ★ 核心功能模块的业务代码：
│   ├── winMain/        # 主窗口管理（控制主窗口的创建、显示、隐藏、置顶等）
│   ├── winLyric/       # 桌面歌词窗口管理（独立窗口的生命周期控制）
│   ├── tray.ts         # 系统托盘及托盘右键菜单管理
│   ├── hotKey/         # 全局快捷键注册监听模块
│   ├── sync/           # 多端数据同步服务模块
│   ├── openApi/        # 提供给局域网的外部 HTTP API 控制接口
│   └── userApi/        # 用于解析加载用户自定义音源脚本（JS 代码隔离运行沙盒）
├── worker/             # Node.js Worker 线程（专门处理解析等 CPU 密集型任务，不阻塞主进程）
└── utils/              # 仅供主进程使用的工具函数
```

### 3. `src/renderer/` (主界面前端 - 渲染进程)
基于 `Vue 3` 的纯前端项目。如果你需要 **修改界面样式** 或 **添加新功能页面**，关注这个目录。
```text
src/renderer/
├── main.ts             # Vue 应用的挂载入口
├── App.vue             # Vue 根组件
├── router.ts           # Vue 路由配置，如果你新增了页面，需要在这里注册路径
├── event/              # 渲染进程（前端）内部的事件分发总线
├── assets/             # 静态资源（字体、通用 CSS、图片）
├── components/         # ★ 基础组件库
│   ├── layout/         # 页面布局组件（如侧边栏、顶栏控制区、底部播放条）
│   ├── base/           # 基础交互组件（按钮、弹窗等）
│   ├── common/         # 业务公共组件（如通用歌曲列表表格）
│   └── material/       # 质感/动画类的特效组件
├── views/              # ★ 页面级路由组件（按功能划分）
│   ├── Search/         # 搜索页面
│   ├── List/           # 播放列表/我的收藏页面
│   ├── songList/       # 歌单页面（发现歌单）
│   ├── Leaderboard/    # 排行榜页面
│   ├── Download/       # 下载页面
│   └── Setting/        # 设置页面（各种偏好设置面板）
├── store/              # ★ 前端状态管理（使用 pinia 或类似方案，存放歌曲状态、设置状态）
├── core/               # 播放器核心前端控制（包含 HTMLAudioElement 的调度、歌词解析等）
├── plugins/            # 第三方 Vue 插件
├── worker/             # Web Worker（负责在浏览器端进行一些耗时过滤、搜索计算）
└── utils/              # 仅限前端使用的工具函数
```

### 4. `src/renderer-lyric/` (桌面歌词前端 - 渲染进程)
为了保证“桌面歌词”运行流畅并且不受主界面卡顿影响，开发者将其剥离为了一个独立的精简 Vue 项目。
```text
src/renderer-lyric/
├── main.ts             # 歌词窗口的 Vue 挂载入口
├── App.vue             # 歌词界面的根组件
└── ...                 # 精简的组件和样式代码。如果你要修改桌面歌词的字体、对齐方式、渐变色等，就在这里修改
```

### 5. `src/static/`
纯静态文件目录，这里的资源不会经过 Webpack 打包编译，而是直接 copy 到最终的构建包里面，主要用于一些特殊的预加载脚本。

## 💡 实战指南：如何添加一个新功能？

假设你想添加一个功能：**“一键导出当前歌单到本地 txt 文件”**。
你需要经历以下几个目录的修改：

1. **界面层 (`src/renderer/`)**：
   - 在 `src/renderer/views/List/` 中的列表组件里添加一个【导出】按钮。
   - 按钮点击后，通过 IPC 频道发送请求给主进程。
2. **协议层 (`src/common/`)**：
   - 在 `src/common/ipcNames.ts` 中新增一个事件名：`'list-export-txt'`。
3. **主进程层 (`src/main/`)**：
   - 在 `src/main/modules/` 中监听 `'list-export-txt'` 事件。
   - 收到事件后，主进程调用 Node.js 的 `fs` 模块弹出文件保存对话框（`dialog.showSaveDialog`），并将接收到的歌曲数据写入到 txt 文件中。
